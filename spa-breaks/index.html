Getting the best spa break deal

  • Check what’s included. Some rates include spa access and a treatment; others are room only, with spa use charged extra.
  • Book treatments early. Popular slots go fast, especially at weekends.
  • Go midweek. Countryside spa hotels are often cheaper from Sunday to Thursday.
  • Read the age rules. Many spas are adults-only or have set times for children.

Frequently asked questions

Is a spa package better value than booking separately?
Sometimes. Compare the package price against the room-only rate plus the spa’s own prices for the treatments you want. Packages can include extras like dinner or late checkout that are worth having.
