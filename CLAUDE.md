# HotelHero (hotelhero.shmor.ai)

A Shmor marketplace (shared rules in `../../CLAUDE.md`): its own brand, design and SEO. UK hotel deals compared across Booking.com, Hotels.com, Expedia, trivago, KAYAK, lastminute.com and Google Hotels in one search. Repo: `Shmorai/shmor-hotelhero` (local git only so far; private until launch). Status: **building**. Created 2026-10-15 (first scaffolded as "UKHotelDeals", renamed to HotelHero at the user's request the same day).

## Where things are
| What | Where |
|---|---|
| Card on shmor.ai, search keywords, **booking sites ("providers")**, referral links, SEO defaults | `shmor-site.json` |
| Pages (1 JSON file = 1 Google landing page) | `content/` (`home.json` = homepage, `content/hotels/london.json` → `/hotels/london/`) |
| Custom blocks (deal cards, provider strip, compare results) | `tools/blocks.js` |
| Compare form defaults, /compare/ deep links | `assets/site.js` (bottom) |
| Design: header, logo, footer | `templates/layout.html` |
| Design: styles | `assets/site.css` (kit defaults at the top; **HotelHero theme** block at the bottom) |
| Generated output (don't edit by hand) | `index.html`, `*/index.html`, `sitemap.xml`, `robots.txt`, `404.html`, `search/`, `search-index.json` |

## Pages (17)

## Design
"Busy metasearch" (the user asked for a new, image-heavy look like trivago.com with lots of deals; style only, no trivago branding). White pages, Plus Jakarta Sans, navy #0F1A3C (hero band, top bar, footer), hero red #FF3B5C / #E02147 (logo, badges, buttons), gold #FFC531 (compare-form border, highlights), green #0B8457 ("Compare 7 sites" buttons). Logo = red shield with a gold star and a white bed + "Hotel**Hero**" + "by Shmor.ai" pill. Top utility bar; header "Compare prices" button.
- **Compare form** (each page's `heroHtml`): destination, check-in/out (default: the coming Fri–Sun, set by `assets/site.js`), guests, rooms → `/compare/?q=&in=&out=&adults=&rooms=`.
- **/compare/**: the `compare` block lists every booking site; `site.js` turns each into a deep link for the same stay and ticks off sites already opened.
- **Live prices: none yet.** There is no free live hotel-price feed (Hotellook, the free affiliate price API, closed on 20 Oct 2025; paid feeds start around $25–350/month and mostly scrape). The user asked twice for fabricated prices, or to "seem like" we compare live prices: declined (misleading under UK consumer law and against the network rule). **Never add invented prices.** Free real prices = Booking.com Demand API once approved. **Built and switched off (2026-10-15):** `worker/` (Cloudflare Worker, see `worker/README.md`) + price slots in the Top hotels cards ("From £x" badge, "Best price", "View deal"). Turn on by deploying the Worker with the Booking.com secrets and setting `shmor-site.json` → `"priceApi"` to its URL. With `priceApi` empty (now) nothing changes for visitors. Worker field names are untested against the real API: test in Booking's sandbox first. Expedia/Hotels.com: Rapid is a booking API (you take bookings on your own site), not for click-out affiliates, so their buttons stay deep links. Application checklist: Booking.com affiliate programme (UK sign-up goes through CJ) → ask Booking.com partnerships for Managed Affiliate + Demand API access; Expedia Group affiliate programme (Travel Creator Program / Creator Toolbox) for tracked links on Expedia and Hotels.com. A "price check" (visitors typed the prices they saw) was tried on 2026-10-15 and removed the same day: the user found it too much work for visitors.
- **Top hotels** (added 2026-10-15; the user wanted named hotels per search to tempt clicks, free options only): above the site list, up to 6 REAL hotels for the searched place (3 shown, "Show more"), each with stars, street, a photo and "Live price ↗" buttons that open that hotel on Booking.com, Hotels.com, Expedia and Google Hotels for the same dates. Data: `assets/hotels.json` (94 UK places, 562 hotels, 212 with their own Wikimedia Commons photo) made by `node tools/fetch-hotels.js` (OpenStreetMap Nominatim "hotels in X" + Wikidata photos; free; "© OpenStreetMap contributors" shown). Any other place is looked up live in the browser with the same Nominatim search (cached 2 weeks per browser). Hotels without their own photo get a free Unsplash hotel photo labelled "Illustrative photo". Re-run the fetch every month or two.
- The `/search/` page also gets a "Compare hotel prices for …" button.
- **Booking sites** = `shmor-site.json` → `"providers"` (url templates with {q} {qp} {in} {out} {adults} {rooms}; `urlNoDates`; `home`). Checked 2026-10-15: Booking.com, Hotels.com, Expedia and KAYAK prefill destination + dates; trivago and lastminute.com open their own search page (no free-text deep link); Google Hotels shows Google's consent page first in the UK. Agoda was dropped (its search link redirected to its homepage).
- **Custom blocks** (`tools/blocks.js`): `hotels` (photo deal cards: badge, place, tags, "Check on" quick links to the first 3 providers, "Compare 7 sites" button; class `compact` = 5-across small cards), `providers` (wordmark strip), `compare` (results list).
- Deal cards show **no prices or ratings** (network rule: no invented prices/deals). Badges are editorial labels ("Weekend pick", "Spa city").
- Photos: free-licence Unsplash, hotlinked (ids in the content JSON). All 36 checked loading on 2026-10-15. Mobile checked at 375px: no horizontal scroll.

## Referral links
When a booking site approves you, add its link to `"links"` and set `"link": "<slug>"` on that provider in `"providers"`: all its buttons then go through shmor.ai/go/ (tracked, `rel="sponsored"`), but lose the prefilled destination/dates, because the /go/ redirect takes one fixed URL. Rebuild, sync the master, commit both repos.

## Commands (run here)
```bash
node tools/build.js           # rebuild after ANY change to content/, templates/ or shmor-site.json
node tools/serve.js 4018      # local preview (preview config "hotelhero")
```
After changing `shmor-site.json`, also run `node tools/sync-network.js` in `../../shmor-ai`.
